## Cài nhanh (Claude Code)

1. Tải repo (Code -> Download ZIP), giải nén.
2. Vào thư mục nghề của bạn, copy `claude-code/kv` vào `~/.claude/skills/`.
3. Mở lại Claude Code, gõ `/kv:`. Nhiều nghề thì copy đè vào cùng thư mục `kv`.

Claude web/Desktop và Codex: xem README trong từng thư mục nghề.
