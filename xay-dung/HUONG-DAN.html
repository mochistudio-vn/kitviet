Chọn nơi bạn dùng AI. Cùng một bộ, chạy được cả ba.

  1. Mở thư mục claude-code/ trong bộ này, thấy thư mục kv.
  2. Copy nguyên thư mục kv vào C:\Users\<tên bạn>\.claude\skills\ (Windows) hoặc ~/.claude/skills/ (macOS/Linux). Kết quả: .claude/skills/kv/.claude-plugin/plugin.json.

  4. Đã cài bộ nghề khác? Copy đè vào cùng thư mục kv, các bộ tự gộp. Bản Pro copy đè lên bản Free.

Che thông tin nhạy cảm trước.
Dùng kv:an-thong-tin-nhay-cam và kv:soat-bao-mat.
Gõ /kv: không thấy skill nào?Kiểm tra đường dẫn phải là .claude/skills/kv/.claude-plugin/plugin.json. Nếu thành .claude/skills/claude-code/kv/... là copy thừa một lớp. Sau đó mở lại Claude Code hoặc gõ /reload-plugins.
Claude không tự gọi skill?Gọi thẳng tên: "Dùng skill kv:<tên> để ...". Hoặc mở file SKILL.md, thêm vào dòng description cụm từ bạn hay nói.
Không thấy thư mục .claude?Đây là thư mục ẩn. Windows: File Explorer -> View -> Hidden items. macOS: Cmd + Shift + dấu chấm.
Claude web báo lỗi khi tải skill?Tải từng file zip trong claude-web/, không giải nén. Cần gói trả phí và bật Code execution trong Settings.
Cài nhiều bộ nghề cùng lúc được không?Được. Copy đè các bộ vào cùng thư mục kv, skill dùng chung chỉ giữ một bản. Bản Pro copy đè lên bản Free.
Có cần biết lập trình không?Không. Mọi file là văn bản thường, mở bằng Notepad cũng sửa được. Dùng kv:dong-goi-skill-moi để tạo skill riêng từ việc bạn vừa làm.
